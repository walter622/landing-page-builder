# Landing Page Builder

Vamos criar uma landing page de um bloco único pra nove. Qual que é o intuito? Da gente qualificar o lead que vem dooo, do Meta pra não vir direto pro WhatsApp, pra vim pra landing page, tá? Eu vou te mandar os textos, vou te mandar ooos criativos que eu quero que você coloca nooo, nos produtos, tá? Pode ver que vai ter alguns produtos com preço. Você vai fazer um carrossel com os criativos que já estão prontos, tá bom? Pega a identidade visual desses criativos, eu vou te mandar o logo da campanha, vou te mandar também o logo da marca. Pode seguir com base nas cores dos criativos, mais o vermelho da marca, mais preto, tá bom? Atue como um designer sênior

aguarde os textos e fotos
